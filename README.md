# DatapackEditor

A Minecraft 26.2 mod for Fabric and NeoForge.

Run `/datapack-editor editor start` with administrator permission, then open `http://127.0.0.1:8700/`. The editor supports workspace files,
overrides of loaded datapacks, recipe and loot previews, advancement trees, 
configured feature previews, and datapack ZIP exports.

Build both loaders with `./gradlew build` using Java 25. Gradle builds the Preact UI.
